## Features

- **Structured JSON output** replaces prose sentinels — resumed sessions now work reliably thanks to CLI-enforced --json-schema output
- **Merge-resolve flow** — label issues with `ai-resolve-merge` to merge, resolve conflicts, and push in one Claude session
- **Session and worktree persistence** — issues now resume their prior Claude session and reuse existing worktrees instead of restarting pipelines from scratch
- **Fleet telemetry server** — new telemetry-server binary with dashboard, live log archive viewer, worker status card grid, and push-ingest API for monitoring worker fleets
- **Status-line integration** — new `loope status-line` command to integrate loope with Claude via your shell status line, with automatic install/remove helpers
- **Post-ship code review loop** — code reviews are now recorded, resumable sessions that park issues on failure instead of silently completing

## Fixes

- **Engine reliability** — improved stop/shutdown to preserve WIP, prevent re-runs after failures with persisted done marker, treat structured "blocked" as hard failure
- **Schema enforcement on all Claude calls** — --json-schema with completion gate enforced on both fresh and resumed turns
- **Worktree reuse** — intelligently reuse existing worktrees instead of deleting and recreating; remove only stale directories
- **GitHub integration** — server-side label exclusion, prevent duplicate comments on timeouts
- **Telemetry resilience** — unsent lines retained until confirmed, rotation-aware log tailer, graceful shutdown with stale-worker pruning
- **Sentinel parsing** — `PIPELINE_ALREADY_DONE` now requires its own line, fixing false terminations from quoted references
- **Debug flow escalation** — stalled sessions with no commits escalate to `ai-needs-info` with questions posted as comments
- **UAT checklist rendering** — now uses GitHub task-list checkboxes instead of plain bullets
- **Feature pipeline resume** — confidence gate now applied on both fresh and resumed brainstorm turns
- **POSIX shell compatibility** — status-line wrapper uses `bash -c` for environments where `/bin/sh` is dash

## Docs & chores

- **Worker flow test matrix** — added 9 flow-level tests covering every pipeline phase crossed with every interruption mode

- **Release artifacts** — pipeline now ships worker tar.gz binaries and multi-arch telemetry-server container images
- **Configuration reference** — loope.json.example fully annotated with all config fields including models.codeReview and telemetry blocks
